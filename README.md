# PacManGame# Pac-Man Clone in Java 👾

A classic Pac-Man game built with Java Swing and Object-Oriented Programming (OOP) principles. 

## 🎮 Features
* Grid-based movement and wall collision detection
* Ghost mechanics (random pathing and border detection)
* Score tracking and life system
* Reset and next-level implementation
